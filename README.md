#  VALIDADOR DE CPF 
Repositorio para Validar o cpf utilizando python como aplicação.
# Objetivo
Este repositório contém um sistema de validação de CPF desenvolvido em Python. O objetivo principal é implementar o algoritmo de Cálculo de Dígitos Verificadores, garantindo que o número fornecido pelo usuário seja matematicamente consistente com as normas da Receita Federal Brasileira. O projeto visa evitar a entrada de dados inválidos em sistemas de cadastro e exercitar o tratamento de strings e lógica de programação.
